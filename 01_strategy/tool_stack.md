# 工具配置

## 必備工具

| 類別 | 建議工具 | 用途 |
| --- | --- | --- |
| 趨勢研究 | Perplexity | 每週搜尋台灣與亞洲穿搭趨勢、關鍵字、商品候選 |
| 圖像生成 | Grok Imagine | 固定虛擬人物、換衣、場景圖、短影音素材 |
| 資料庫 | Notion 或 Airtable | 管理人物設定、提示詞、內容排程、商品連結、成效 |
| 排程 | Metricool、Buffer 或 Later | IG、Pinterest、TikTok/Threads 排程與基本分析 |
| 連結追蹤 | Bitly、UTM、GA4 | 追蹤每則內容的點擊與轉換 |
| 私域名單 | LINE OA、MailerLite 或 ConvertKit | 收集名單、推送清單、測試付費產品 |
| 設計排版 | Canva | 封面、carousel、簡報式穿搭清單 |

## 變現工具

| 類別 | 建議工具 | 第一階段用法 |
| --- | --- | --- |
| 台灣聯盟 | 蝦皮聯盟、本地品牌聯盟 | 優先測商品點擊與成交 |
| 全球聯盟 | Amazon Associates、ShopMy、LTK | Pinterest 長尾與全球商品補充 |
| 付款 | Gumroad、綠界、藍新、Ko-fi | 販售提示詞包、穿搭指南、諮詢 |
| 社群 | LINE OA、Discord、Instagram Broadcast | 累積會員與推播內容 |

## 自動化工具

| 階段 | 工具 | 自動化內容 |
| --- | --- | --- |
| MVP | 手動 Perplexity + CSV | 先確保選題有效，不急著開發 |
| 半自動 | Zapier、Make | 趨勢研究輸出同步到 Notion/Airtable |
| 穩定後 | Perplexity Sonar API | 每週自動生成趨勢候選與商品關鍵字 |
| 成熟後 | 自建腳本或輕量後台 | 自動產生提示詞、UTM、內容排程草稿 |

## 不建議前 90 天投入

- 自建 SaaS 後台。
- 自有庫存或打樣。
- 複雜 AR 試穿。
- 大量付費廣告。
- 多人物 IP 同時經營。
