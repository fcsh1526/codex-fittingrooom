# Mira：IG 穿搭 Reel 研究與鏡頭設計修正

觀察日期：2026-09-22。研究狀態：完成首輪篩選與畫面抽樣；尚未完成參考片逐幀切點、連續動態及音樂分析。新片型是待驗證提案，W37 不恢復量產。

## 結論

Mira 要保留親切、精緻的服裝雜誌定位，但影片中的動作與切鏡必須增加服裝資訊。上一版「看書 → 鬆開書本」主要推進生活動作，沒有充分推進穿搭內容。即使人物穩定、兩個鏡位銜接正確，仍可能只是延長一張穿搭照。

前一輪 COS／Massimo Dutti 等參考只完成美術與有限畫面觀察，沒有足夠的完整鏡頭分析。不能把新試片稱為已落實大品牌的鏡頭語言。也不能從這次便利樣本推出「IG 現在一律偏好幾秒、幾鏡」的規則。

接下來以「同一組疊穿，兩種配色關係」測試畫面能否自己說明內容；先驗證鏡頭之間的服裝關係，再調片長、音樂和必要文字。閱讀／花藝的生活感可保留，但道具不再決定主要動作。

## 1. 這次實際查了什麼

- 8 個帳號的初始 Reels 網格，共 93 筆公開觀看數；其中 10 筆置頂、83 筆非置頂。
- 從中打開 21 支，核對文案、公開日期、播放器片長，並在播放器不同時間點擷取畫面觀察。
- 93 筆不是 93 支完整看過；21 支也不是全部連續看完。未量測每支的所有切點、平均鏡長、BPM、留存或自然／付費流量。
- 抽樣時間是讀取播放器時間後緊接截圖，可能有小幅延遲；不作逐幀時間碼使用。時長只報到一位小數。
- 觀看數是介面顯示的累計約數，不等於觸及。同帳號貼文也有不同發布天數，不能直接視作控制實驗。
- 這是便利樣本，先看較高觀看，再加內容對照。大帳號較多，不能聲稱代表所有台灣女性或 IG 全站。
- FUDGE 的一支共同發文導向 fudge_snap；仍是原 93 筆中的同一支，不重複計數。

帳號涵蓋 Lydia、Alex、Thanya、FUDGE、PAZZO、GU Taiwan、chouchou_rei_rei 與 Tori。原始網格保留在 [grid_sample.json](grid_sample.json)，逐支觀察與證據層級在 [reel_observations.json](reel_observations.json)。本報告不使用搜尋引擎轉載數字替代已登入 IG 的當次數據。

## 4. 把「明快、簡潔、舒服」變成可以控制的決策

以下是從觀察提出的製作假設，還不是觀眾成效已驗證的公式。

| 使用者要的感覺 | 實際控制什麼 | 如何判定，而不只填參數 |
| --- | --- | --- |
| 明快 | 每鏡新增的服裝資訊、剪掉等待動作開始與結束後的空檔 | 說得出新鏡讓觀眾多看到什麼；只有眼神、笑容、手離開書本，不足以獨立支持切鏡 |
| 簡潔 | 一支只有一個可見的比較主張；每鏡一個主要資訊 | 換場景、道具、字幕、景別、動作不一起搶主題；若刪掉一鏡沒有損失，先刪 |
| 舒服 | 相鄰畫面的視線落點、尺度、背景與亮度關係 | 換衣服時尽量保留觀看位置；改景別時保持同套衣服與方向。不要同時大幅換衣、換場、換位置、換曝光 |
| 有動態 | 正常速度、用途明確且已在進行中的短動作 | 人物一個自然步伐或整理外搭使輪廓可見；不以放慢生成或全片加速處理拖沓 |
| 雜誌感 | 全片一致的配色、留白、服裝選擇與攝影語氣 | 成片整體有一致性，不能靠「cinematic」提示詞、濾鏡、Logo 或慢動作代替 |
| 可持續 | 同一鏡頭功能可套用不同週次；特殊動作另測 | 複用的是「整套—重點—對照—整套」的關係，不是每週同一個摸書／抬花姿勢 |

「10個參數都正確，組起來仍很怪」的判斷是合理的。還要檢查相邻兩鏡的關係，以及整支的資訊順序。單鏡、相鄰鏡頭、完整成片是三層驗收；數值不是最後裁判。

### 拍攝／生成與剪輯的分工

- 生成端：提供正常速度的單一可用動作，保留完整衣服和身份；每鏡一個主要動作、至多一個運鏡。固定攝影機仍可用。
- 剪輯端：選動作已開始、有服裝資訊的區間；可在動作中銜接，不必每鏡等人物停穩才切。
- 顯示端：先以無字幕版本檢查穿搭是否成立，再加入有必要的最少文字；音樂加入後再做完整有聲驗收。無字版是檢驗方法，不代表正式發布永遠不准有字。
- 轉場：先看相鄰畫面是否連得上。直接切鏡不是自動通過，也不是自動不舒服；推移、溶接同樣不保證順暢。

## 5. M02 下一版的可檢查測試設計

**提案狀態：未生成、未通過視覺核准。這一版約10.4秒／4鏡是測試設定，不是本研究算出的 IG 最佳值。**

可見主張：同樣是薄襯衫＋洋裝，第一套呈現灰／奶油白的淺色關係，第二套呈現霧藍／深藍的深淺關係。保留當週兩套衣服，先把這個差異拍清楚。不用「涼爽、舒服、顯瘦」等無法由生成畫面證明的性能主張。

| 建議選片區間 | 畫面任務 | 接到下一鏡的理由 |
| --- | --- | --- |
| 0–2.8秒 | L01全身，開頭即看見完整造型與鞋；一個正常速度的短步或身體角度變化，讓外搭與裙的輪廓分開 | 觀眾已看到整套，下一鏡回答層次是如何形成 |
| 2.8–4.8秒 | L01肩至腰／上腿的重點畫面，襯衫敞口、洋裝領口與前襟都清楚；動作直接讓這個關係可見 | 固定領口／前襟的觀看位置，準備比較第二套 |
| 4.8–6.8秒 | L02相近尺度與服裝重點位置；霧藍外搭和深藍方領形成明確對照 | 先比較搭法，再退回整體觀看第二套 |
| 6.8–10.4秒 | L02全身，完整看清洋裝長度、鞋包與整體比例；正常速度的簡單動作收束 | 結尾保留可讀的完整造型，不再強加快速雙套回顧 |

兩個重點鏡頭的背景亮度與人物位置須特別接近；有意改變的是服裝色彩。若圖書館與花藝場景無法做到，就先重設背景或構圖，不能靠過場硬接。具體位置與動作起點仍須在起始圖製作單中確認；既有圖不保證可用。

這和上一版的差別不只是從14秒減到10秒，而是中央兩鏡直接建立「兩套如何不同」的關係，移除為了生活情境而存在的道具動作。四個畫面功能確定後，才依 mira-image-daily 流程檢視既有素材是否適配，列出確實缺少的起始圖；不先預設必須重生四張。

### 第一個可停止或通過的檢查

1. 不看文案／不靠字幕，能否辨認两套的外搭與內搭配色關係？若看不出，改主張或鏡頭，不能先加解說補洞。
2. 全身鏡頭是否看清完整造型，細節鏡头是否新增資訊，而不是重複上一鏡？
3. 中央換套是否容易跟上，沒有強烈亮度跳變、視線跳躍或閃圖感？須看成片，不只核對素材。
4. 動作是否正常、沒有拖長等待？如果素材只有慢吞吞的無用動作，回到生成／動作設計，不用速度調整掩飾。
5. 身分、服裝與肢體的動態 QA 仍獨立完成；使用者接受肢體表現，不等於整支風格已被核准。

通過才擴其他模特兒。新靜態候選仍須使用者視覺核准；正式五支、一人兩套、W37暫停與發布權限不變。

## 6. 帳號操作：可重複的穿搭選擇理由

以下是基於 Mira 產品定位的編輯建議，不是從公開觀看數推導的成長保證。

- 對外持續提供「這週可以怎麼穿」，讓五位虛擬人物成為固定編輯角色。每支有一個可比較、可照做的穿搭關係，不把帳號成長寄託在真人私生活、名人相似或秀場資格上。
- Reel 負責讓人看懂造型與差異；Carousel 保存完整搭配與選擇理由，文案補充季節／場合資訊。不要把全部說明塞進十秒影片。
- 五位、每週五支、各兩套的產線規格保留。先驗證同一種完整片型，再恢復四週內容比較；避免一面改鏡頭、一面改片長、字量、音樂、選題，最後無法知道何者有用。
- 商品路徑可以參考 Alex／Lydia 的穿搭內容接 LTK，但公開留言或連結不是實際成交證據。Mira 先建立可回查的相似款連結，未核對實品時不得說成實穿。
- 先比較自己的同發布天數觸及、收藏／分享／追蹤事件與製作時間。公開樣本沒有留存，不能替 Mira 預測最佳秒數。

## 8. 下一輪補強證據的方式

要訂成固定剪輯模板前，只對內容適配的少數短片補做完整播放、所有切點、聲畫關係與相鄰鏡頭分析；不再用「打開頁面、抽幾幀」冒充逐鏡研究。這次對核心鏡頭功能已有足夠方向性證據，對精確節奏與音樂仍沒有。新一版分鏡因此保持待驗證，不寫成熱門影片成功公式。

每個候選參考至少記錄：發布日期、是否合作／活動、觀看數的觀察日、片長、開場任務、各鏡新增資訊、切鏡前後構圖、字幕／聲音依賴、是否能用一位固定虛擬人物與兩套服裝完成。技術無法完整播放時，保留 unknown，不填入推測值。
