# Mira Reel｜六種影片呈現企劃

狀態：只規劃，暫停起始圖／影片生成與剪輯。

親切的日常服裝雜誌：構圖精緻、光線自然、服裝看得清楚、每段有觀看理由。

每支同一位模特兒、當週兩套；兩套可以共同呈現主題，不必互相比較。

這些是企劃方向，不是六種新剪輯技術。原三類版面分類保持獨立。

## E01 日常片段

想像這樣穿出門的日常感。

- **整支主題：** 輕鬆的通勤片刻。兩套各是一個獨立片段，共享自然光與日常氣氛。
- **當週衣服範例：** W41 M03：米白西外／白T／深藍褲；深藍西外／淺灰T／奶油白褲。
- **觀看順序：** 第一套全身短走、自然停下 → 第二套全身站姿轉斜側，再開始走動。
- **鏡頭與節奏預算：** 先規劃兩個主要鏡頭，各約6–9秒可用來源；成片依實際動作取段。固定鏡頭先行，兩個片段各有起動與收束。
- **場景的用途：** 有頂走道提供通勤與午間外出的空間；可用同一地點的相近角落，光向一致。景物只服務走動路徑與衣服可見性。
- **起始圖與搭配重點畫面需求：** 兩套各一張全身動作起點＋一張可用領口／腰線搭配重點畫面。搭配重點畫面是必備資產，未必入片；走道須有短走空間。
- **銜接設計：** 以相近全身尺度、亮度與穩定落點作0.75秒疊化，明確進入下一個穿搭片段。允許場景有合理差異；不要求人物輪廓完全重合。
- **整片要驗證什麼：** 無字觀看能否感到自然外出，且兩套都看清？步行是否有目的，還是只在等鏡頭？
- **容易失效的地方：** 空間會飄移、短走停頓過長；無目的拿杯子、翻書等手勢容易變成道具表演。
- **研究狀態：** 近／遠與自然戶外動作已有研究；完整日常段落編排仍是提案。

## E02 動態輪廓

看衣服在不同姿態下的線條。

- **整支主題：** 短外套與長褲的俐落比例，讓動作增加服裝資訊。
- **當週衣服範例：** W41 M05：奶油白短外套／可可棕褲；炭灰短外套／淺灰直筒褲。
- **觀看順序：** 第一套正面、自然換重心，露出衣長與褲腰 → 第二套由正面轉淺側身，再回正，讀到側邊輪廓。
- **鏡頭與節奏預算：** 兩個主要全身鏡頭；第一套以站姿變化、第二套以轉側作區別。每段一個主要動作，普通速度，不把兩段都做成相同轉身。
- **場景的用途：** 安靜、明亮的通勤走道；牆與地面提供穩定線條，襯托衣長及褲型，不採伸展台或奢華廣告場景。
- **起始圖與搭配重點畫面需求：** 兩張有腳步留白的全身起點；兩張腰線／外套下襬搭配重點畫面。參照須支援預計側面，完整背面轉圈另測。
- **銜接設計：** 全身接全身、先控制人物高度及重心；0.75秒疊化只承擔柔和換段，不承擔無縫換裝。
- **整片要驗證什麼：** 轉側是否真的新增下襬與褲型資訊？兩套全身是否有足夠不被疊化覆蓋的閱讀時間？
- **容易失效的地方：** 整段慢擺拍、腳步打滑、包突然變形；360度會暴露尚未設計的背面。
- **研究狀態：** 淺轉、換重心及並排轉身已有試作；這裡改為以服裝輪廓組織兩個不同動作段落。

## E03 細節帶出全身

先注意服裝特色，再理解整體搭配。

- **整支主題：** 格紋是亮點，素色下身保留畫面的清楚程度。
- **當週衣服範例：** W41 M01：兩套格紋襯衫與素色長褲；只採當週已定案的格紋、褲色與鞋包。
- **觀看順序：** 第一套帶臉的上身／腰線 → 同套全身 → 第二套全身 → 第二套帶臉的上身／腰線。
- **鏡頭與節奏預算：** 候選四鏡：3＋5＋5＋3秒，扣三次0.75秒疊化後約13.75秒。中間全身各約3.5秒完全清楚；數字是預算，不是最佳秒數。
- **場景的用途：** 兩套保持同類光線與簡潔背景；中景包含領口、格紋與素色褲腰，避免只拍一塊無上下文布料。
- **起始圖與搭配重點畫面需求：** 每套全身＋原生中景，共四個可用畫面。若尺度銜接需要連續退後，改規劃鏡內距離變化並另測，不以裁切動畫冒充拍攝。
- **銜接設計：** 每個接點寫共同服裝焦點；中景與全身差太大時先改分鏡，不能只靠疊化。四鏡版本閱讀時間不足便減鏡。
- **整片要驗證什麼：** 關掉文案是否仍能讀到格紋＋素色的關係？細節是否比全身新增資訊？景別變化是否舒服？
- **容易失效的地方：** 像簡報輪播、特寫過小、人物大小撞眼；細袖口接觸不能當作必需動作。
- **研究狀態：** Missy細節帶出整體的歷史觀察與既有D版可借用；不是新發明的剪輯形式。

## E04 配色氣氛

感受一組容易想像穿出門的色彩。

- **整支主題：** 米白、深藍與灰的安靜通勤色彩；兩套是同一色彩專題中的兩幅動態照片。
- **當週衣服範例：** W41 M03：第一套淺外層與深褲；第二套深外層與淺褲。呈現共同色彩世界，不宣稱哪套更好。
- **觀看順序：** 第一套完整色塊與自然斜站 → 第二套完整色塊與短走／停穩。必要時加一個帶腰線的同套中景，強化實際衣服色彩。
- **鏡頭與節奏預算：** 先採兩個全身鏡頭，必要才增第三鏡。節奏來自姿態與構圖改變，避免色塊卡、標籤及抽象道具占去服裝時間。
- **場景的用途：** 選米灰牆與自然日光，避免背景引入大面積搶眼新色；服裝、膚色及地面維持同一曝光氣氛。
- **起始圖與搭配重點畫面需求：** 兩張色彩與亮度一致的全身圖＋兩套領口／腰線搭配重點畫面。服色以核准服裝為準，不為調色改成別種顏色。
- **銜接設計：** 先匹配整體明暗，再0.75秒疊化；不要求頭、手、腳全部重合。亮度變化若像閃白便回到起始圖修正。
- **整片要驗證什麼：** 兩套是否形成一致的色彩印象，且觀眾看得清真實搭配？畫面精緻度是否壓過親切感？
- **容易失效的地方：** 變成品牌廣告或只有色調、沒有衣服資訊；色溫漂移導致服色失真。
- **研究狀態：** 色塊組織已有buufen歷史觀察；無字、非教學的配色短篇仍待實作。

## E05 配件串聯

看一件配件如何融入兩套完整衣服。

- **整支主題：** 一只鈷藍小包，串起兩個素色日常造型。焦點是包與衣服的位置及色彩關係。
- **當週衣服範例：** W41 M04兩套均有鈷藍小包：白T／炭灰褲；白襯衫／黑中長裙。其他周須先核實共有同一配件。
- **觀看順序：** 第一套全身 → 第一套包與腰線中景 → 第二套同類包／腰線中景 → 第二套全身。
- **鏡頭與節奏預算：** 候選四鏡5＋3＋3＋5秒，扣疊化後約13.75秒。包保持自然背著；不以細手勢、空中拿放或手把特寫作核心。
- **場景的用途：** 安靜書店門廊等符合日常外出的場景；中景仍有衣服上下文，兩套保持包的主要落點相近。
- **起始圖與搭配重點畫面需求：** 兩套各全身＋包／衣服關係搭配重點畫面，共四畫面。近景須保留黑色帶、包型及所搭上衣／下身，清晰度不足才補圖。
- **銜接設計：** 用包的位置與顏色引導視線，兩套中景間0.75秒疊化；全身與中景的尺度跳動仍需分開處理。
- **整片要驗證什麼：** 觀眾是否看得出包融入整套造型，而非一段孤立商品廣告？兩套完整下身及鞋是否仍看清？
- **容易失效的地方：** 包帶／手包接觸變形、只拍包而丟失搭配；不可把虛擬圖說成實際商品實穿。
- **研究狀態：** 配件觀察與對應細節銜接已有研究；這次把共同配件作為整支企劃主軸。

## E06 明確兩套比較

快速做一個具體穿搭選擇。

- **整支主題：** 只在兩套確有一個看得見、值得比較的差異時使用。
- **當週衣服範例：** W41 M03可比較淺外深下與深外淺下的色塊；多個單品同時改變，不宣稱某一件造成顯瘦等效果。
- **觀看順序：** 相同尺度的兩套全身同時可見 → 各自自然淺轉；或兩套相同全身景別依序出現。
- **鏡頭與節奏預算：** 並排可是一段6–10秒來源且沒有片內換鏡；依序版本有一次0.75秒疊化。二者屬不同版面，同一比較企劃。
- **場景的用途：** 共同背景與光向，人物在窄面板內安全移動；不同步動作可保留，不能改速強制同步。
- **起始圖與搭配重點畫面需求：** 兩套各全身＋差異可讀的搭配重點畫面。並排要先檢查手機上衣服是否太小、完整鞋包是否被裁掉。
- **銜接設計：** 並排固定版面不需要轉場；若切換素材則仍遵守0.75秒。相似構圖不等於無縫換裝。
- **整片要驗證什麼：** 不看字幕是否能知道比較什麼？手機觀看是否能做選擇？沒有明確差異便選其他企劃。
- **容易失效的地方：** 每週都變成A/B選擇題、服裝在窄面板中太小；不能因技術容易就成為唯一形式。
- **研究狀態：** M02並排與錯開轉身已核准，W41 M04左右版已交付；目前無本帳號成效證據。

## 深化次序與條件

建議先深化E01與E02，先看生活感與動態輪廓。新圖及新片皆未啟動。時長、角度為候選預算，不是IG最佳規則；每份分鏡須寫服裝資訊、場景用途、動作端點、光向、相鄰銜接、閱讀時間與缺圖。0.75秒柔和疊化、無字、原速保留，整片正常速度驗收仍必要。
