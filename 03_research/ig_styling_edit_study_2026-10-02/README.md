查核日期：2026-10-02。用途：提供 Mira 下一輪可測的剪輯假設；W37 五支已接受影片由使用者先發布測曝光，沒有因本次研究重新修改或發布。

接續研究：[第二輪：台灣／日本同帳號多支比較](round2/README.md)，含五支播放取樣及下一次 M03 資訊順序試驗製作單。第一輪提案保留為當時的候選，不是唯一已驗證方向。

## 結論

最適合目前 Mira 的參考方向是「服裝細節帶出完整搭配」與「固定構圖下比較造型」。本輪能看到：明快感可以來自每次畫面換掉時都增加新的服裝資訊；人物不必加快動作。這是從畫面順序提出的假設，仍需 Mira 的完整試片與發布成效驗證。

約 0.75 秒柔和交疊、人物原速、一人兩套、成片不加文字，全部保留。來源中的硬切、密集換裝、口述或字幕，不會直接成為 Mira 的製作要求。

## 把觀察轉成工作流能控制的因素

這些是候選製作設定，沒有宣稱為 Instagram 的最佳參數。

| 因素 | 可操作的設定／驗收 | 來源或理由 |
|---|---|---|
| 整支的訊息 | 一句話描述兩套共同的穿衣問題；每個鏡頭指出它展示的具體特徵 | 避免只有姿勢與無意義場景 |
| 畫面順序 | 每次換鏡新增服裝資訊；寫明「細節→整體」或「A 的特徵→B 的對應特徵」 | Missy 的組裝順序、Lydia 的服裝變化 |
| 接鏡位置 | 剪接前比對兩端人物／主體中心、尺度、目光位置、背景線條與亮度 | Missy 多造型與 Reika 的固定構圖 |
| 尺度變化 | 全身接細節前先找共同視覺焦點；不把大幅位置跳動交給交疊補救 | 使用者先前對全身／近景切換的不適回饋 |
| 動作銜接 | 接在手已就位或動作仍連續的片段；避免前鏡停住再由下一鏡重新啟動 | 完整播放判讀停頓感；不改人物速度 |
| 轉場 | 約 0.75 秒 cross dissolve；不另加模糊、閃白、幻燈片移動 | 使用者已選定的全域規則 |
| 看清時間 | 記錄每鏡未被交疊覆蓋的秒數；中間鏡要扣掉前後兩段交疊 | 避免四個鏡頭看似夠長，實際一直在淡入淡出 |
| 音樂 | 另行於 IG 選音樂後完整播放，確認節奏與服装閱讀時間；先保留無音軌交付 | 本輪沒有音訊／節拍證據，不先定 BPM |
| 整體驗收 | 正常速度連續播放，判讀是否看懂兩套、是否閃眼、是否像簡報；單項參數合格不等於整片合格 | 對應使用者指出的組合問題 |

### 交疊的時間預算

四鏡各 3.25 秒、三次交疊各 0.75 秒，成片約 `4×3.25−3×0.75＝10.75 秒`。

首尾鏡各有約 2.5 秒未交疊時間，中間鏡各約 1.75 秒。這只是一個可試設定；來源須有足夠連續可用片段，不得靠凍結或加速補足。近景若看不清衣料／領口，應改簡化內容或延長，不能把計算結果視為驗收通過。

## 下一輪可測的三種資訊結構

| 候選 | 一位模特兒／兩套的結構 | 要驗證的事 |
|---|---|---|
| 1. 細節先引起興趣 | A 搭配重點 → A 完整造型 → B 完整造型 → B 對應重點 | 少量文字甚至無字時，觀眾是否能從細節理解服裝特色；借用 Missy 的细節帶出整體 |
| 2. 先給兩套比較 | A 完整造型 → B 完整造型 → A/B 有共同功能的重點 | 第一輪兩套展示是否夠清楚；以同尺度、同位置安排比較，借用 Reika 的構圖連續性 |
| 3. 對應細節銜接 | A 完整造型 → A 重點 → B 對應重點 → B 完整造型 | 同一部位或配件的切換能否更舒服；現有 M03 已有這種結構，可作基準，不能宣稱為新的研究成果 |

共同功能必須由當週衣服成立。例如兩套都靠領口疊穿，才可以比較領口；不能為了模板捏造同款、同商品或實際試穿證據。此處是剪輯假設，尚未開始新起始圖或新影片生成。

### 建議先做的單一試驗

W37 先照已接受版本發布，建立本帳號基準。下一個技術候選先驗證「細節先引起興趣」：同一人兩套、約 10–11 秒、0.75 秒交疊、無文字、原速。完成後要完整播放評估，才決定是否採用。

若要比較曝光，使用同一模特兒與可比的穿搭主題、發布位置、音樂類型及發文時間；每次主要改一項資訊順序。來源不夠連續時先處理素材，不能同時改動作、速度、鏡頭數與轉場再說是順序的效果。兩週不同衣服仍有內容差異，成效只能作方向判斷，需要重複。
