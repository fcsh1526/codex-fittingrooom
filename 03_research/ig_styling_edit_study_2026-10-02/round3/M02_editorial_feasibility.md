# M02 下一輪可見比較｜資訊與素材可行性

日期：2026-10-02。範圍：依既有兩套穿搭、核准 D 版及 pilot 製作紀錄提出下一輪候選；本輪沒有生成、重新剪片、改動來源或新增核准。只讀紀錄並查看既有 A2／B2 選段取樣板和 v4 A／B 取樣板，沒有連續播放。評估依 `mira-image-daily` 的 Reel 素材規劃與現行 Reel SOP：一人兩套、無字、來源人物動作／速度不改、後續切換約 0.75 秒交疊。

**建議先明確「敞開襯衫下的領口與兩層配色」這一個比較問題。四鏡倒序本身沒有新鏡頭語言；它回到 M02 最早試過的四鏡順序。兩段連續推近／拉遠、一個換裝接點更值得作比較候選，但這也已在核准 pilot v4 試過。新的 0.75 秒交疊版本、任何補圖或新運鏡，都仍需另外驗收。**

## 1. 畫面能回答的問題

主問題候選：**「同樣敞開襯衫配洋裝，淺色弧領與深色方領，會呈現什麼不同的領口與前襟關係？」**

對應畫面主張：兩套都讓洋裝領口從敞開前襟中露出；A 是霧灰外層＋奶油白內搭，B 是霧藍外層＋深海軍藍內搭。觀眾先看見完整造型，再在同一觀看位置看內搭顏色與領口邊界，最後回到另一套全身比例。

依 [weekly_look_plan.csv](../../../10_automation/runs/2026-W37/weekly_look_plan.csv) 的 `2026-W37-001-L01/L02` 與本輪實看的選段取樣板：

| 可以從現有畫面比較 | 畫面上的證據 | 主張界線 |
|---|---|---|
| 淺內搭與深內搭在敞開襯衫中的關係 | A 的奶油白弧線領口與霧灰前襟；B 的深藍水平／方形領口與淺藍前襟 | 兩套同時變了領口與顏色，不能把視覺差異歸因於單一因素 |
| 敞開前襟是否讓內搭洋裝保持可讀 | A2/B2 同時保留領口、前襟、腰及部分裙身；外層没有遮住整個內搭 | 可以呈現層次；不能據生成畫面宣稱透氣、保暖、舒適或顯瘦 |
| 領口搭配如何放回完整日常造型 | 全身包含裙長、鞋、包，能看見搭配的上下關係 | 鞋、包與背景也不同；這是兩套建議，不是只變一件單品的實驗 |

無字片最基本的可讀目標是觀眾能說出「兩套都敞開襯衫，裡面一套淺色、一套深色，領口形狀不同」。**是否能在正常播放中讀出這個主張仍未知**；不能只因近景有領口就認為觀眾已理解。

原主題「可拆式輕薄疊穿」保留作情境，但现有四段沒有脫下外層、單穿洋裝或進出室內的示範。這些素材不能直接證明「如何可拆」或「應付溫差」，也不能把 S03 的意外滑肩當拆穿教學。下一輪不宜同時把領口比較、脫穿操作及冷氣／室外對照全塞進無字短片。

## 2. 倒轉 D 的真正新意與限制

已核准 D：`A2 疊穿中景 → A1 全身 → B1 全身 → B2 疊穿中景`，8.75 秒、三次 0.75 秒交疊。核准範圍是此支乾淨畫面；不代表使用者已接受所有資訊順序。

提議的 `A1 全身 → A2 中景 → B2 中景 → B1 全身` 把領口對照移到中央，把整體造型放在首尾。這是可測的資訊排序差異，但**就是 [storyboard_comparison_v2.md](../../../10_automation/runs/2026-W37/reels/pilot_M02/storyboard_comparison_v2.md) 的原始四鏡路徑**。當時 2026-09-24 的使用者回饋已指出：兩側全身／中景的尺度跳變刺眼，中間相同景別換裝有驚喜。不能把這個順序寫成新的研究發現或新的帳號形式。

真正可能新增的試驗問題，是「套用現行 0.75 秒交疊後，中央領口對照是否更易讀、兩側是否更舒服」。結果尚未觀察。若只重排既有四段，臉、包、姿勢與背景的錯位仍在；柔和交疊只能改變切換過程，不能替素材建立連續空間。

### 現有選段的閱讀時間

按 [source_selection.json](../round2/M02_D_structure_trial/source_selection.json) 原區間原速重排，總長仍為 `3.25+2.50+2.00+3.25−3×0.75＝8.75 秒`。下列只是剪輯時間帳，不是平台最佳值：

| 位置 | 選段長度 | 扣掉前後交疊後的單獨畫面時間 |
|---|---:|---:|
| A1 全身，片頭 | 3.25 秒 | 2.50 秒 |
| A2 中景，中央 | 2.50 秒 | 1.00 秒 |
| B2 中景，中央 | 2.00 秒 | **0.50 秒** |
| B1 全身，片尾 | 3.25 秒 | 2.50 秒 |

中央 B2 放到中間後要承受兩次交疊，只有約半秒不重疊的畫面。這會削弱「先看清方領／前襟再比較」的目的。原 D 把 B2 放片尾，只有一次交疊，單獨可讀時間約 1.25 秒；倒序不是免費增加比較清楚度。

B2 來自 `S03_comparison_v2_02.mp4`，核准 D 只用來源 0.25–2.25 秒；完整來源約 3.47 秒起曾滑肩。不能為中央閱讀時間直接延長到舊退件區間、降速、凍結或反播。任何另選區間都須重新 QA，不能沿用整片核准。

四鏡仍可能像四張簡報：各自開始一個走步或扶衣襬動作，景別變化與手的位置也分開啟動；一鏡只有「換了尺度」卻沒有新增可讀信息，就會像為湊素材而切鏡。鏡內有微動、四段都是真影片，也不能據此排除簡報感。此處只是由紀錄與抽樣提出的風險，沒有宣稱本輪完整觀看已判定失敗。

## 3. 兩段連續運鏡、一個換裝接點

候選路徑：**A 全身平順推近至領口／前襟 → 相近尺度換 B → B 拉回全身。** 服裝信息仍經過四個節點，但只有兩段獨立來源與一個組片接點。優點是同套的全身／中景由鏡內連續變化交代，不必兩次重啟人物姿勢；中央保留同部位對照。

這不是新構想。[storyboard_scale_continuity_v4.md](../../../10_automation/runs/2026-W37/reels/pilot_M02/storyboard_scale_continuity_v4.md) 已依原四鏡的不適回饋設計此路徑；[核准 v4 紀錄](../../../10_automation/runs/2026-W37/reels/pilot_M02/M02_scale_continuity_v4_review_01.json) 記載：

- `A_scale_push_v4_01.mp4` 取 0–2.5 秒；`B_scale_pull_v4_01.mp4` 取 0–4.5 秒。
- 原生來源運鏡、原速、無後製數位放大；當時只在 2.5 秒直接切換。
- A 尾與 B 頭的臉／肩尺度接近；B 在選段內展示完整裙、包與鞋。
- 7 秒無字無音畫面於 2026-09-29 獲使用者核准。部分早期 storyboard／generation records 還保留 pending；本片核准以較晚成片 JSON 及 pilot README 的補記為準。

所以可合理把兩鏡方案放在倒序四鏡之前評估：它針對的是曾發生的尺度與姿勢跳變。**兩鏡不自動更清楚或更精緻。** 推近可能太快略過領口，拉回可能先離開重點；相近尺度的一個接點仍會同時換服裝與圖書館／花藝背景。

若用上述相同原區間改做 0.75 秒交疊，理論片長是 `2.5+4.5−0.75＝6.25 秒`。這是尚未製作的新候選。交疊中 A 仍在推近、B 已在拉回，可能形成移動中的雙尺度重影；原先「A 最後一幀接近 B 第一幀」並不證明整段 0.75 秒都匹配。不能據原 v4 核准自動接受這個版本，也不把 6.25 秒當最佳片長。

若現有兩段沒有足夠的清楚領口閱讀區間，新的來源應在分鏡階段保留接點前後可读的中景，先讓領口／前襟成立，再繼續拉回全身。這是未來素材要求，不是授權補圖或保證生成可做到；已有來源的角色動作與速度保持原樣。

## 4. 原素材不足與下一輪選擇

| 原素材不足 | 對下一輪的影響 | 合理處置候選 |
|---|---|---|
| A/B 是圖書館與花藝工作坊，背景物與亮度不同 | 中央領口比較同時要處理場景變化；花／書架雙影可能搶走衣服 | 先如實保留不同生活場所。若補素材，再從整支同場景設計倒推兩套的匹配構圖，不任意換景 |
| A2/B2 的手、包、頭頂及服裝焦點没有完全對齊 | 同景別不等於能平順交疊；動作容易像各做各的 | 比對實際接點，優先讓領口／前襟在相同觀看區；不能為對齊而改速或接受裁掉服裝證據 |
| B2 只剩較短的已核准早段 | 倒序中央純閱讀時間只有约 0.5 秒 | 不預設倒序四鏡為首要方案；不擴用退件晚段 |
| 小幅扶下襬展示前襟，但沒有脫穿操作 | 可以證明敞開層次，不能證明可拆步驟與溫度調節 | 將本片主張收在可見的領口／配色對照，避免功能承諾 |
| v4 原生運鏡已可作比較，但新的柔和交疊尚無驗收 | 可減少獨立接點，仍可能背景重影或縮短重點閱讀 | 保留核准原 v4 與核准 D 作參考；新片另記 source intervals、交疊與完整播放结果 |

**下一輪建議：先把兩套共同主張收在「敞開外層中，內搭領口／顏色如何可見」，再優先評估既有兩段原生運鏡能否支持這個主張與現行柔和接點。** 倒序四鏡可作資訊排序診斷，但应明列它回到原 v2，且現有 B2 中央閱讀時間不足；不是先驗更好看的新模板。

若需要新素材，同一背景、相近中景尺度、前襟不遮領口及足夠原速閱讀時間，是優先條件。M02 v3 face/full 仍為 approved，兩檔本輪已確認存在；這只支持人物參照可用。**新的運鏡、背景幾何、肩袖／領口／鞋包穩定性仍未知，任何新生成是否可行均須實測；不能由已核准靜態或舊 v4 推定。**
