# 穿搭影片深入拆解｜第三輪

研究日期：2026-10-02。目的：把「明快、簡洁、舒服、親切的服裝雜誌感」轉成可供 Mira 分鏡、起始圖和整片驗收使用的要求。第一波五支影片已在 Drive，發布及受眾成效仍未知。本輪沒有生成新素材或改動核准影片。

## 結論

**可借用的核心是每鏡新增有用的服裝資訊，以及兩套共享一條觀看路徑。** 鏡頭快慢、數量和轉場時間，單獨都不能保證這件事。固定背景、相近人物大小、相同觀察部位會降低重新定位的負擔；動作或近景須帶來前鏡沒有的服裝資訊。

這是視覺機制的判讀，尚未證明它提高 Mira 的曝光。來源都有各自的商業、文字和音樂條件。本輪靜音播放，沒有音訊、拍點、留存或後台數據。

Mira 保持一人兩套、約 0.75 秒交疊、人物動作及來源速度不改、無畫面文字。這些是已確定的專案規則；不是此次來源研究得出的 IG 最佳參數。

## 一、逐序拆解：鏡頭為什麼出現

下表的時間只是代表畫面的觀察區間。它們不能拼成精確鏡頭起止表；空隙內可能還有未列出的動作或切換。

### Kubo 秋季：共同舞台支撐比較

| 代表畫面 | 可見內容 | 鏡頭的用途與 Mira 取用方式 |
|---|---|---|
| 0.04–0.13、0.76–0.85、1.51–1.60 秒 | 三套依序出現，均為朝左側面、相近全身尺度 | 預告服裝差異。Mira 不取用密集預覽；保留相同觀察位置的機制 |
| 2.34–2.45、3.10–3.18、4.53–4.61 秒 | 第一套正面、碰袖口、側面 | 分別給上下比例、上衣細節與輪廓；新增角度有服裝用途 |
| 6.07–6.15、6.87–6.96、7.58–7.67 秒 | 第二套正面、側面、背面 | 換服裝後重複相似觀察路徑，讓差異容易定位 |
| 10.55–10.63、11.40–11.48、12.17–12.25 秒 | 第三套同區域正面、側背 | 共同舞台保持一致；Mira 仍只兩套 |

新證據釐清了前輪低時間值出現第二套的疑點：影片實際有三套側面預覽，不能再把它只當作不同步。詳見 [獨立順序審查](kubo_sequence_review.md)。來源第一套離場接第二套進場會把人從左邊換到右邊；移植成 0.75 秒疊加，可能出現雙位置的人。固定背景不會自動解決這個接點。

### Missy 初秋：近景帶出可見的搭配關係

| 代表畫面 | 可見內容 | 新增資訊 |
|---|---|---|
| 0.03–0.18、0.76–0.96 秒 | 手持外套與鞋，再見白 T＋灰牛仔基底 | 先知道有哪些衣服，基底比例清楚 |
| 1.44–1.60、2.60–2.83、3.25–3.44 秒 | 手持鞋、已穿外套的領口／衣料中近景 | 鞋與外套的材質配色、短外套與腰線關係 |
| 3.84–3.99、4.43–4.61 秒 | 眼鏡、棕色手提包靠近畫面 | 補配件，沒有再重拍一張無新資訊的半身擺姿 |
| 5.05–5.21、6.99–7.16、7.59–7.76 秒 | 完整含鞋造型、側面、背面 | 前面的細節回到整套，確認褲長、鞋和外套輪廓 |
| 9.97–10.11、10.50–10.66 秒 | 完整穿搭中抬腳／靠近 | 收束展示；不能由自動重播宣稱無縫循環 |

這支的近景有明確的服裝任務。Mira 可借「材質／領口→整體比例」的關係，但生成影片不必模擬手持鞋、穿鞋、轉背或整套組裝。來源也有開場文字、商品導流和較快換景，並非直接驗證了 Mira 的無字雙套格式。

### Missy 紅外套：動作承擔資訊，不只是裝飾

0.08–0.26 秒見紅外套與鞋；1.37–1.54 秒見白上衣／牛仔褲基底；2.00–2.17 秒見拿外套；2.60–3.40 秒已穿外套，立領和短衣長可見。3.81–4.61 秒給鞋及拋鞋動作；5.08–5.86 秒加入斜背包；6.30–6.48 秒整理眼鏡；6.88–9.48 秒以全身、側向與正面姿勢確認成套；9.99–10.16 秒靠近離場。

可借用的是「每次加入一件物件，畫面都有可見改變」以及最後回到完整造型。不能把這支的活潑感只歸給片長；它有組裝、道具和動作，與 Mira 已穿好衣服的慢動作來源不同。未分析聲音，拋鞋是否與拍點同步未知。

### Kubo 兩色：比較問題一開始就可見

0.47–0.64 秒兩套同時完整出現；2.51–2.68 秒兩欄皆呈側向；4.56–4.71 秒可見背面；6.62–6.78 秒回到正面附近。兩欄動作並非每刻完全同步，顏色和穿法也不只改一個物件，因此不能稱嚴格的單因素試驗。

它減少了「先記住 A，再找 B 相同部位」的負擔。Mira 可借同角度比較，雙欄需另外設計原生構圖，不能把現有 9:16 全身來源裁半就使用；衣服會變小，手機閱讀需另驗。此方向列為後續候選，尚未採用。

### Kubo 褲型：近景證明具體問題

2.67–2.81 秒第一尺寸正面，3.84–7.85 秒代表圖提供側／背輪廓；9.98–11.38 秒看到腰臀、口袋和腰頭。13.29–14.64 秒另一個尺寸全身可比。18.07–20.68 秒展示腰頭位置及調整；21.69–24.31 秒是腰帶及穿帶；25.29–30.15 秒回完整、側背造型。32.04–33.11 秒為黑底商品尾卡；這次才確認尾部，舊循環邊界圖不能當尾幀。

近景有用，是因為它回答腰部與褲型的問題；它保留上衣、褲腰與臀部上下文。Mira 能借同部位示意，不能用生成影片主張真實尺碼、實穿合身或扣具功能。品牌尾卡也不移植。

### Floral 抓皺：問題→差異→方法→結果

0.07–0.27、1.30–1.48 秒是原穿法；2.51–2.67 秒先見抓皺效果。3.68–6.30 秒捏布／內折；7.33–9.99 秒工具近景；11.27–12.78 秒局部放大固定過程；13.76–17.99 秒完成、紮入與位置示範；19.05–20.48 秒再作上下前後對比；21.47–23.45 秒品牌卡。

它適合借內容結構：讓觀眾先看到差異，再解釋差異如何成立。來源用大量文字與示範，不能推論拿掉文字後方法仍完整可懂。Mira 無字影片優先示意兩套的可見輪廓、配色和層次，方法或材質選購理由放貼文；不生成扣針教學作功能證據。

## 二、把形容詞變成可控制要求

| 想要的感覺 | 分鏡／選片可控制的內容 | 整片會失败的組合 |
|---|---|---|
| 明快 | 每段回答一個服裝問題；新資訊出現時才換鏡；選取已有的可用動作階段 | 只有姿勢變化，服裝資訊不變；多鏡頭只讓同一件事重複 |
| 簡潔 | 一個共同情境、一個比較軸；兩套重複相同觀察部位 | 同時換場、改尺度、改方向、改光線，觀眾不知要比较哪件事 |
| 舒服 | 換裝接點比人物大小、中心、頭肩、衣服重點和背景線；保留約0.75秒交疊 | 景別差太大時拉長交疊，會延長雙尺度人影；新鏡從停住開始會有重啟感 |
| 服裝雜誌感 | 配色、衣料、層次有編輯主題；完整造型與重點相互解釋 | 每張都漂亮但沒有共同問題，整片成為圖片清單 |
| 親切 | 場景服務通勤／室內外等日常選擇，正常人物距離和實際可見服裝 | 用奢華場景或無意義環境取代穿搭內容；道具擋住真正要看的領口或腰線 |
| 可持續 | 固定規劃欄位、配對接點、品質與時間紀錄；一次先驗一支 | 固定所有鏡數與秒數，卻不問本週服裝是否真的有相同可見重點 |

**具體提案，不是已驗證門檻：** 換裝接點先以人物中心偏移不超過畫寬5%、主要部位垂直偏移不超過畫高5%、人物尺度相對差不超過5%作警示值；用來源末段與下一段首段實測，不從 prompt 字句判定通過。即使三者合格，背景線、方向與動作階段仍需一起審查。數字用來找問题，不能代替整片正常速度觀看。

### 0.75 秒交疊的閱讀預算

交疊期間兩張畫面都在，所以要另外記真正單獨看清的時間。若四段各3.00秒、三個接點各0.75秒，總長為9.75秒；兩個中間段各只剩1.50秒不在交疊內。這是時間算式，不是最佳片長規則。讀衣服仍不夠，就增加有效畫面時間或減少資訊，而非把人物加速。

實際 M02 選段也支持這項限制：B2 只用已核准的早段0.25–2.25秒，共2秒。原D版放片尾，扣一次交疊後有1.25秒單獨畫面；若移到中央，前後各扣0.75秒，只剩0.50秒。比較部位相同仍不一定比較清楚。不得為補時間延長至已知滑肩的退件晚段，詳見 [原選段](../round2/M02_D_structure_trial/source_selection.json) 和 [可行性分析](M02_editorial_feasibility.md)。

### 接點是配對審查，不是各鏡分別打勾

在分鏡階段先列出前鏡退出的構圖和下鏡進入的構圖。生成後看交疊開始、中點、結束與前後完整動作：人物是否在同一觀看位置、主要衣服部位是否對應、背景是否出現明顯雙線、衣服有沒有瞬間跳變、交疊外是否足夠看清。最後必須看整支，不能用截圖 QA 宣布觀看舒服。

## 三、下一輪的實際改進位置

查回歷史後，「全身A→中景A→中景B→全身B」正是 M02 先前 v2 的順序；兩段原生推／拉也已在 v4 技術試片出現。因此這些不能包裝成新剪輯方向。詳見 [M02 可行性查核](M02_editorial_feasibility.md)。

下一步優先建立 **兩套的共同場景與構圖條件**。當週資訊先定一個可見比較問題，再畫兩套接點；從相同場景、視線方向、人物位置和觀察部位倒推來源，保持目前 D 版作已接受的順序選項。新素材、不同長度和不同音樂會引入其他因素，不能把新片與舊片曝光差稱為單純剪輯因果。

M02 可作規劃例：共同題目是敞開薄襯衫下的兩組內外配色與領口對照。霧灰／奶油白及霧藍／深藍由畫面可見；領口、敞開前襟、腰線與兩層邊界是有用重點，肩帶只有實際可見才列入。實際厚度、透氣與穿著舒適度不能由 AI 畫面或穿搭計畫驗證；本片只主張可見的領口、配色與敞開層次。

建議規劃同一個明亮圖書館入口／座位區，兩套保持50mm、胸高水平視線、同一光向及固定背景幾何；普通日常空間提供親切情境，避免複雜反光與來往人群。每套仍先核准原生9:16含鞋全身，再判斷既有衍生重點畫面清晰度；不預設必須新增四張。領口重點保留臉、雙肩、外層邊缘和足夠洋裝上下文，避免僅一張無法理解搭配的包／布料照片。

本輪交付是可執行的規劃與查核方式；沒有要求現在重做第一波，也沒有新來源可用秒數或動態合格率。下輪先完成配對分鏡與起始圖示意，核準後再做一支技術片，再依整片驗收决定能否量產。

## 四、來源與成效的界線

第一、二輪的網格累計觀看數字留作 [既有研究](../README.md)／[第二輪](../round2/README.md) 背景。本輪不重新排名成效：粉絲基礎、發布時間、合作分發、商品導流、字幕與音樂都不同，沒有可比後台。不能說184萬來源的片長或硬切造成流量，也不能把小帳號的低數字當內容無效。

來源有三種可見商業路徑：Missy 貼文的 SHOP／商品連結、Kubo 商品／官方搭配資訊、Floral 工具和顧問服務。Mira 可在服裝資訊後對應實際或相似商品，但生成造型仍屬示意，不能主張實穿證據。當前不接觸購買、不留言或詢問創作者。

新找到的 Lydia、miku、Yuan 和 itsyuyan 原始候選僅查 metadata，未播放，另列 [觀看佇列](source_discovery.md)，不計入六支拆解。後續補樣本可擴內容形式；本輪先把接點、可見服裝問題和歷史試作差異弄清楚。
