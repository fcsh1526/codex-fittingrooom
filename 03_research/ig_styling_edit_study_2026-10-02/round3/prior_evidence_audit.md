## 核心限制：取樣板不能代替時間線

兩輪製板程式都以 `currentTime` 全域排序。第一輪把兩次循環的相似時間混在同一板；第二輪也混合循環，並從全部樣本中均勻選取最多 15 張。因此，板上相鄰格不等於原始連續取樣，相鄰格之間也可能跨過未顯示的鏡頭或動作。不能用板上的格数數切點、算平均鏡長，或把板讀成一條經核對的連續時間線。

第二輪 README 已記錄「時間在截圖前讀取，存在延遲」。每張圖的六位小數只代表當時介面讀值的精度，不代表截圖內容的準確影片時間。特別在跳轉、影片重載或播放回到開頭時，畫面和讀值可能分屬不同時刻。尚未驗明同步前，只能寫「兩張圖中顯示不同造型／角度」；不能捏造精確切點。依時間排序也無法修復錯配。

## 可控制的因素，以及組合容易失敗的地方

這些是分鏡与選片能控制的因素，沒有把任何設定直接視為通過。約 0.75 秒、原速、無字是本專案的使用者決定；不是來源替我們驗證的最佳參數。

| 可控制因素 | 寫入分鏡／選片的具體內容 | 單项看似成立，組合仍會失敗的原因 |
| --- | --- | --- |
| 服裝資訊順序 | 每鏡新增什麼：領口層次、腰線、下襬、鞋與褲裙的關係、配件與衣料；指出細節如何指向整套 | 美的近景如果沒有衣服上下文，觀眾可能只看見包或鞋，不知道它解決哪個穿衣問題。細節→全身順序本身不保證無字可懂 |
| 兩套共同觀看位置 | 記人物／衣服重點在畫面的位置、大小、角度及亮度；對應兩套的同一部位 | 換衣同時換場、換景別、換方向、換亮度，會要求眼睛一次重新定位數件事。0.75 秒交疊只會把這些不同畫面疊在一起 |
| 全身與細節的主體對應 | 在全身中先能看見即將展示的部位；選片比較上一鏡終點與下一鏡起點的衣服重點 | 包從右側小物變成中央大物、鞋位置移動或全身突然變無臉近景，會形成雙尺度重影。四段各自合格仍可能讓整片閃眼 |
| 現有動作的選入／選出 | 保留原動作與速度，選定已有連續可用區間；記前鏡正在發生什麼、後鏡從何階段接入 | 每鏡都從停住開始、等姿勢落定才結束，会形成重啟感；兩套方向相反也可能沒有比較理由。不能靠改速、凍結或轉場補足不可用區間 |
| 交疊与衣服閱讀時間 | 每個接點留來源 handles，另記完全沒有交疊的區間；中間鏡扣掉前後两次交疊 | 「四鏡各夠長」仍可能一直在淡入淡出；細節可見只剩很短時間。`4×3.25−3×0.75=10.75 秒` 是時間預算，不能證明衣料看清、觀看舒服或節奏自然 |
| 場景的用途和幾何 | 指出場景如何支援兩套共同情境；接點比對固定線條、透視、光線与背景物件 | 兩張靜態圖各自漂亮、身份相符，仍可能沒有匹配幾何；交疊会加重背景雙影。不能因圖有四張就把它們當四段可連續動態 |
| 片尾的收束 | 寫最後一鏡新增或確認什麼服裝資訊；先讓動作与主題成立，再決定是否需要循環 | 自動重播不是剪輯設計。硬把尾部接到第一鏡，可能使服裝資訊倒退、動作跳回或一直不收束；不強制做循環 |
| 親切雜誌感 | 場景有日常用途，人物與服裝可信；構圖、配色和材質清楚，鏡頭之間有編輯理由 | 固定鏡位可乾淨，也可能像商品列表；生活場景可有沉浸感，也可能喧賓奪主。不能以鏡數少、柔和轉場或高級配色單獨宣稱風格成立 |

## 音訊与公開數據的因果邊界

既有索引有部分音樂標籤，例如 Missy 的 `Veni Sun — Window Eyes` 与 Kubo 的三個曲名；這只支持頁面顯示該標籤。現有研究沒有核對實際可聽片段、起音位置、速度、節拍、切鏡是否踩拍、原音／口述的份量或音樂的可使用範圍。截圖中的靜音圖示不代表來源影片無音訊。不能用曲名推 BPM，也不能只看視覺變化說它「跟著拍子」。

下一次若能可靠連續播放聲音，應分開記錄「哪一個可聽事件」与「哪一个視覺事件」，以實際前後觀察支持同時發生。不能把大致節奏感變成毫秒同步。Mira 保留無音乾淨母版，音樂選定後另看完整成片，避免聲音讓服裝閱讀顯得急促或使原本的停頓更突出。

所有網格數字是 2026-10-02 當日可見的累計值；沒有可比發布齡、觸及／非粉絲、留存、投放、粉絲來源、合作分發或收藏／分享後台。Kubo 秋季是共同貼文，Missy 有折扣／SHOP，Floral 是服務／商品示範，Reika 是置頂舊片，均不能把數字差異歸給剪輯。也不能由台灣與日本兩個帳號推論兩地受眾共同偏好。

Mira 的發布網址和相同發布齡成效尚未在本稽核中取得。没有数据不能填零；既有三支 D 畫面接受不能當成曝光實驗已完成。日後看同齡表現时，衣服主題、音樂、發布時間與分發条件仍是混雜因素；結果可提供複測方向，不保證因果。

## 新觀察的最低記錄方式

保留原始採集次序與播放圈，另存可供比較的時間排序；不得只存混合循環的板。先確認整個直式影片區域都可見，再描述鞋、全身與服裝重點。資料至少分開記：來源網址、畫面內容、原始採集序號、讀取時間前／後值、是否播放、是否跳轉／重載、時間同步可否驗明，以及實際聽到的內容。

若讀值為 null、paused=true、突然回到 0 或與畫面衝突，該次仍可作視覺截圖證據，但时间標記為未知，不能插值補秒數。切點只在同步已確認的可靠來源中記精確時間；否則写「先看到領口，後看到完整搭配」「並列兩套一起轉向」等可直接確認的順序。連續觀看、逐幀、正常速度舒適度與抽圖各自另記，沒有做的項目維持未知。
