# Mira Instagram 每日穿搭內容對標研究

研究日期：2026-08-11  
研究範圍：Instagram 公開頁面；不登入私人帳號、不製造觀看或互動、不投放廣告。

## 1. 研究目的

補上 Mira 原工作流缺少的內容策略階段：在生成圖片或影片之前，先確認每日穿搭內容為何值得受眾停留、繼續看、收藏或分享。

本研究不把粉絲數直接等同內容成效，而是觀察：

- 帳號目前是否仍以每日穿搭、極簡服飾或造型建議為核心。
- 近期公開貼文主要使用 Reel 或 Carousel。
- 首圖／首秒先讓觀眾看到什麼。
- 一篇內容如何安排人物、服裝、動作、環境與細節。
- 文案提供的是情緒、情境、穿搭方法，還是購物轉換。
- 公開互動是否來自內容本身，或被「留言關鍵字取得連結」放大。

## 2. 資料限制

這是公開資料快照，不是帳號後台分析：

- 公開頁面不穩定顯示觸及、收藏、分享與 Reel 觀看數。
- 部分帳號隱藏按讚數。
- 因此按讚／粉絲比只能當粗略代理值，不能視為真正觸及率或互動率。
- 互動數是研究當下所見；之後仍可能增加。
- `kziiee` 三篇精確按讚數沿用使用者現場紀錄；公開頁面在研究時只顯示部分四捨五入數值。

## 5. 跨帳號共同模式

### 5.1 不是 Reel 或 Carousel 單獨決定成效

- Lydia 以 Reel 做造型教學。
- Anouk、Felicia、kziiee、Una 和 AnChen 的近期核心內容大量使用 Carousel。
- 成熟帳號的普通貼文可以高於 Reel；Mira 現階段 Reel 有初始推薦流量，則是帳號分發條件不同。

結論：Mira 應把 Reel 當目前的「發現入口」，但內容設計必須學習高互動 Carousel 的完整敘事，不能把靜態圖隨意加動態就當 Reel。

### 5.2 有效內容分成兩個引擎

#### 引擎一：實用決策

結構：

```text
一個具體困擾／場合 -> 首秒看見差異 -> 一套簡單公式 -> 結果 -> 可保存理由
```

代表：Lydia、Life With Jazz。

適合題目：

- 同一件上衣，上班與下班怎麼換。
- 雨天通勤，薄外套怎麼穿才不顯厚重。
- 小個子如何穿寬褲而不壓身高。
- 25–30°C 冷氣房，外層怎麼選。

#### 引擎二：沉浸式身份

結構：

```text
人物穿著完整造型進入場景 -> 景別與動作變化 -> 環境／物件呼吸 -> 情緒或事件收尾
```

代表：Anouk、Felicia、kziiee、Una、AnChen。

觀眾保存的不是單一衣服，而是「我也想這樣度過一天」的身份想像。

### 5.3 首圖／首秒有兩種合格答案

1. **立即可比較**：同一基礎單品的兩個結果、穿對／穿錯、白天／晚上。  
2. **立即可進入**：完整服裝已在具體場景中行動，構圖、材質和情緒同時成立。

不合格答案：人物先喝咖啡、走入鏡頭或停在遠處，過幾秒才讓觀眾理解服裝主題。

### 5.4 一篇只需要一個穿搭命題

高流量教學內容通常不在一支影片塞入整週趨勢。它只回答一個問題。沉浸式內容也只維持一套服裝、一個地方與一段時間。

### 5.5 Caption 有兩種有效寫法

- **編輯式**：一個地點、季節或短句，讓圖片完成敘事。
- **實用式**：場合＋公式＋原因＋自然搜尋詞。

初期 Mira 較適合「短編輯標題＋一個實用理由」的混合寫法；不能只寫抽象氛圍，也不需要冗長商品 CTA。

### 5.6 留言需要辨識來源

- `Comment SHOP/DETAILS` 會提高留言，但反映索取連結，不一定表示觀看或內容喜愛。
- 人物關係、幽默收尾和具體問題產生的留言，更接近自然共鳴。
- Mira 的早期判斷仍應優先看平均觀看、前三秒／略過、收藏與分享；留言數不能單獨判讀。

## 6. Mira 的建議內容定位

Mira 不應成為：

- 只有漂亮 AI 模特兒的圖片帳號。
- 把每週趨勢名稱直接當受眾標題的研究摘要帳號。
- 靠靜態圖片微微推近、沒有明確內容命題的 Reel 帳號。

Mira 應成為：

> 以高級紀實雜誌影像，替 20–35 歲女性解決每天一個具體穿衣決策。

品牌差異不是「AI 圖很漂亮」，而是：

```text
可模仿的穿搭公式 + 一段讓人想進入的日常片刻
```

## 7. 工作流必須新增的前置關卡

舊流程：

```text
趨勢研究 -> 選衣服 -> 生圖 -> 做 Reel／Carousel
```

修正流程：

```text
趨勢研究
-> 台灣當週氣候與場合
-> 受眾的一個穿衣決策
-> 一句停留理由
-> 內容引擎（實用決策／沉浸式身份／混合）
-> 首圖／首秒證據
-> 完整畫面序列
-> 圖片或連續影片生成
-> 發布與指標
```

在生成前，每個項目必須先回答：

1. 今天是哪個具體場合？
2. 觀眾正在猶豫什麼？
3. 這套衣服提供什麼答案？
4. 第 0 秒如何讓答案可見？
5. 看完後有什麼值得收藏？

任一題沒有答案，暫停生成。

## 8. Mira 可重複使用的內容模板

### 模板 A：15 秒發現型 Reel

```text
0.0–1.5 秒：完整造型已在動作中；一句具體命題
1.5–5 秒：服裝輪廓與比例清楚，不能仍在等待人物入場
5–9 秒：外層、褲線或包袋產生有意義的自然動作
9–12 秒：以轉身、調整衣襬／肩帶或走過光線呈現材質
12–15 秒：人物完成一個動作並自然離場／停定；不能讓手懸空
```

規則：必須是連續真實動作，不用三張圖片拼成影片。

### 模板 B：6–8 格沉浸式 Carousel

```text
1. 全身 Hero：服裝＋場合立即成立
2. 中近景：人物連結或上身輪廓
3. 動作全身：步伐、坐下、轉身或拿取物品
4. 服裝細節：材質、袖口、腰線、鞋包
5. 環境呼吸頁：交代這一天的空氣
6. 第二人物角度／活動片刻
7. 背面或遠景：補尺度與離場感
8. 靜物或情緒收尾：包、鞋、桌面、門口、雨水等
```

不是每篇都必須 8 格，但不能連續放 6 張構圖相近的模特兒照。

### 模板 C：混合 Caption

```text
[一句日常情境／穿衣問題]
[三件核心單品的公式]
[一句比例、材質或場合理由]
[可選：自然收藏提示]
```

例：

```text
雨天通勤，外套不必厚重。
橄欖短版薄外套 × 奶油白無袖上衣 × 深藍高腰直筒褲。
短上身和俐落褲線，讓防風層看起來仍然輕。
把這套留給下一個下雨的上班日。
```

## 9. 套用至 W33-001

研究後，W33-001 的受眾標題不應直接使用研究分類「輕量防護外層」，建議改成：

> 雨天通勤，外套不必厚重

穿搭答案：

```text
橄欖短版無內裡薄風衣
+ 奶油白無袖棉質上衣
+ 深藍高腰九分直筒褲
+ 米白低筒休閒鞋
+ 深棕小肩背包
```

目前 Grok 影片的前半段已比咖啡 Reel 更快看到完整服裝，但內容命題仍未在首秒成立，後段又出現無目的的抬手。若繼續製作，影片動作應服務於「薄外套在雨天通勤仍然俐落」這個答案，而不是只有人物走路。

## 10. 研究結論

1. 使用者先前的判斷正確：衣服是核心，但高流量內容不是單純展示衣服。
2. 成熟穿搭帳號同時依賴「可採用的穿衣答案」或「可沉浸的生活身份」，最強內容往往兼具兩者。
3. Carousel 在成熟帳號中仍非常重要；Mira 現階段使用 Reel 是為了取得初始推薦，不代表內容必須採用短促、低資訊的 Reel 形式。
4. 首秒必須讓觀眾立即知道穿搭問題或直接看到完成造型，不能再用無脈絡的咖啡、等待或細微推近開場。
5. Mira 的生成工作流要新增「受眾停留理由」關卡；先有內容命題，再寫圖片與影片提示詞。
