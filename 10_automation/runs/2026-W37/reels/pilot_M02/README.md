## 決策

- T02/T03 都穩定且 T01 較差 → 原核准圖先保留，採人物參照路徑，再小批驗證其他模特兒。
- T02/T03 不穩定、T05 穩定 → 先採正面影片起始圖；至少重複驗證 T05 再量產。
- T02/T08 各自穩定、T09/T10 混衣或漏鏡 → 分別生成兩套，後製直接切鏡；不重做所有穿搭。
- T06 或 T07 才失敗 → 限制該動作／運鏡，保留能通過的低動作模式。
- 都不穩定 → 不量產；先检查實際參照是否被選取、模式是否一致，再縮短或縮小動作。視覺完整的靜態試剪可保留，不冒稱動畫已解決。

此十次試驗只有診斷價值，樣本不足以宣稱成功率。正式 Reel 將按 `09_sops/mira_reel_production_sop.md` 的 15 秒骨架組裝；M02 pilot 用 **A：同一問題、兩套解法**，主張為以可脫薄襯衫應付室內冷氣與室外溫差。需要的细節畫面仍須逐一確認；兩張全身圖不自動等於六段影片素材已齐。
