## 接點先配對

唯一交疊目標：A來源5.25–6.00秒／B來源0–0.75秒，兩者均是全身，攝影機不在同時推拉。比較**整段**重疊而不只兩個端幀：人物中心、頭肩、身高占比、腰線、裙／鞋、手包方向及背景固定線條。以畫寬／畫高5%偏移、人物尺度相對差5%作找問題的警示值，沒有視為通用合格門檻。

場景的木書架、窗／座椅和地板線須固定；光線不能在鏡內突然移動，臉、肩袖、領口與鞋包不可變形。既有四段D及兩段v4不能自動成為本次來源，尤其不能擴用B2滑肩的晚段。

## 起始圖倒推與核准順序

1. **L01 全身master（本次候選）**：完整臉、裙長、鞋包；建立共同場景與衣服基準。它供A拉遠時作服裝參照，不是A的中景First frame。
2. L01 重點First frame：從核准全身衍生，保留同身份、精確衣服與場景幾何；含臉及領口／前襟。中景與全身是素材需求，不強制指定兩張為起終幀。
3. L02 全身master：獨立新look鎖定。共用核准場景／構圖，但衣服只依L02來源與週資料；灰色托特包、米白便鞋、深藍方領及霧藍襯衫不與L01混用。
4. L02 重點proof：依L02核准全身選取或衍生；新圖需核准。可先作服裝驗收依據；B預計從全身進入，不能憑舊花藝近景推定新的領口及背景正確。

新生成A先核准再衍生。參照名錄M02 v3 face/full為approved且已開啟查驗；其衣服與中性背景不作本週穿搭來源。舊圖與舊核准不覆寫；新素材在各look的 `reel/paired_scene_v1/`。
