# W44 Reel 製作檢討

範圍：本週影片製作與交接，不延伸判定十套完整素材或 Carousel 完成。使用者確認本週影片需求已完成。交接結果：先前五支單套片，加上四支方法追加片；追加 M02 同路線片廢棄，原單套 M02 不受影響。尚無發布成效資料。

## 主要判斷

現有流程已規定觀眾看點、整片分鏡、共同場景與原速驗收。本週問題主要是執行沒有落實：加速製作偏向同類單鏡；多鏡接點、尺度與節奏到後製才處理；抽樣與解碼被當作交片依據，讓使用者承擔了本可先發現的問題。不能全部歸因於 Grok。

## 證據與改善提案

| 本週觀察 | 下週建議 |
|---|---|
| 五支單套獲接受，但使用者仍要求其他形式 | 週企劃先列每片看點與觀看方式，保留形式變化，不固定五方法全做。 |
| M01 並排與 M02 前後人物尺度不一致 | 起始圖合成到實際成片版面，檢查頭頂、鞋底、人物畫高、視線與包的安全範圍；對等比較可先以人物畫高差不超過約5%作內部試用值，非已驗證硬標準。 |
| M02 多次補接仍遭廢棄 | 先測最難的接點，再擴成全片；每次只改一個核心變因。同一機制連續兩次失敗即重新設計或改列研究，不繼續補片湊數。此為待採用的試作預算。 |
| M05 柱面過場過長，使用者要求1秒 | 用秒數定義服裝可讀與遮擋區間；把「部分遮擋、全遮、揭開」分開記錄，避免整段來源直接串接。1秒先作本片及相近遮鏡的比較基準，不推為所有轉場硬規則。 |
| 固定鏡頭活潑表演獲接受，小跑則有刻意與比例問題 | 每鏡一個有動機的主要動作，清楚寫起點、高潮及終點尺度。保持動作幅度選項；行走與小跑仍可測，不視為禁用。 |
| Grok 回覆失敗時實際已生成三片，另有上傳引用殘留 | 上傳後確認精確素材UUID與內容；失敗先查生成紀錄，再決定是否重送；生成時間與工具傳輸延遲分開記錄。 |
| 多次稱已剪完，但完整原速動態驗證未完成 | 分開標記生成、初剪、技術檢查、動態審查及使用者接受。若工具無法可靠連續觀看，明示缺項，不能用解碼、縮圖或免審授權取代。 |
| 四支追加交接只附TXT，文案仍留給發布端 | 下週統一交付有效版本、對應文案、封面建議、音軌狀態、禁用版本與已知限制；依既有SOP補原生Google Docs交接。不要讓後端重新辨認版本。 |

## 建議執行節奏

看點與形式分配 → 實際版面中的靜態尺度檢查 → 必要接點短測 → 來源製作 → 立即原速粗剪 → 動態／接點／整片審查 → 統一交接。

成熟製作與方法研究並行；研究失敗不得阻塞已可交付影片，也不得靠換片名宣稱方法成功。研究結果分為本片接受、重複成功、發布成效三層。

## 下週應記錄的量

每支生成次數、可用來源秒數／總生成秒數、修改原因、主動作及接點缺陷、生成與等待時間、使用者追加修正次數、實際發布後留存與互動。現有資料不足以回推精確成本、效率提升百分比或觀眾偏好。

本文件是檢討與改善提案，未改動已接受影片、最高流程或技能。
