# M02 五套沿路換裝｜20秒同步預演提案

使用者澄清此方法的核心是人物在行進中換多套衣服，並選「比照之前五套」。此指示取代剛才12秒單套路段設定。五套概念／數量已選定，以下新服裝、20秒時長、路線及接點仍是待看提案，沒有新寫實圖或Grok生成。

觀眾看點是同一深靛無刷破直褲的五天上班搭配：白襯衫、藍條紋襯衫、燕麥薄針織、淺灰薄西外、白T帆布鞋。全部同一M02、同一公司、同一場地／人物與相機時鐘。變裝代表不同工作日，不是故事裡當街脫換衣服。五套服裝完整清單見 five_look_wardrobe_proposal.json。

四個換裝中心為4、8、12、16秒，每處沿用0.75秒柔接比較基準。五段共享人物位置、方向、步相、相機位置、朝向、地標與光線時間，不在換裝點停步或重開ease。前18秒依弧長前進，18–20秒在入口前自然減速。相機走獨立曲線，非固定平移人物。

停下來：人物已在有目的地前進，第一套白領與深褲清楚。繼續看：一路維持動勢，下一套服裝按路段揭示；人物越接近公司，相機逐漸回前側。記住我們：同一條深靛褲搭成五天正式度，而非五個不相干的場景。

新增需求：本片沿用本週兩套，另提三套系列穿搭，正式週五主題／十套／五支Reel基準不改。新增三套各需Reel全身與proof、Carousel A/B/C，共15個素材角色。路線生成另至少需要共用寫實場地參照、五套首尾共10張精確路線視圖；角色可重用時須審核，不把角色數誤當最終新增圖數。五套均需新場景全身來源；剛才門邊候選未核准且不能當路線首圖。

先看五套服裝與本版俯瞰／相機預演。定案後導出最少首／中／尾圖，逐圖確認再動態；先短測最難的換裝接點，檢查整段18格的尺度、步相、腳位與背景，不只對齊單張。實際工具時長、生成可用區間及接續能力需觀察，不宣稱這條軌道已能精密執行。
