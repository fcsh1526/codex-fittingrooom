# W34 Publishing Structure

W34 contains five themes, one model per theme, and two complete looks per model: ten looks total. Every look now requires both Reel and Carousel source packages. The previous 7-Reel/3-Carousel split is retired.

## Required assets per look

- Reel: one separately composed 9:16 full-person source image. It becomes one shot in a weekly compilation.
- Carousel A: full-person Hero with the complete outfit readable.
- Carousel B: scene application showing the outfit working in its intended occasion.
- Carousel C: accessory detail showing the key bag, shoes, scarf, belt, or jewelry in relation to the outfit.

Carousel A/B/C are designed for the existing three-image connected Canva template. They preserve the same model, exact outfit, styling placement, and photographic character, but each frame has a distinct editorial role.

## Reel compilation options

1. One Reel containing all ten looks.
2. Two Reels of five looks each:
   - Reel 1: the first look from each of the five models/themes.
   - Reel 2: the second look from each of the five models/themes.

Each look contributes one shot. The final edit chooses one of the two compilation options; it does not create ten separate Reels by default.
