# Instagram Visual Direction

Purpose: keep the account image-led, fast to understand, and commerce-friendly without making posts feel like sales flyers.

## Current Direction

The account should feel like:

```text
virtual person in believable daily outfits -> visual attraction -> light caption -> profile / affiliate link
```

It should not feel like:

```text
text-heavy carousel -> comment bait -> shopping list pitch
```

## Carousel Format

Use a 3-slide panorama:

```text
3240 x 1350 px
export as 3 slides, each 1080 x 1350 px
```

Slide roles:

1. Image-led hook. No required text.
2. One short transition sentence.
3. Image-led ending. No CTA wall.

The template should use composition, crop, whitespace, typography, and color rhythm to create the aesthetic. Text should not carry the post.

## Copy Rules

Avoid:

- comment bait
- "留言..."
- "我整理平價 / 質感 / 替代款"
- large AI disclosure text on the image
- dense hook frameworks
- too many labels on the carousel

Use:

- one quiet mood sentence in the carousel
- short caption
- profile-link shopping direction
- minimal disclosure in caption: `AI 生成虛擬造型影像。`

## Image Rules

Prioritize:

- believable lifestyle moment
- outfit visible within one second
- less posed body language
- ordinary daily setting
- clear garment shape
- no logo or brand-signage focus

Reject:

- overly polished AI beauty-shot feeling
- mannequin-like pose
- runway / editorial exaggeration
- heavy text overlay
- images that need a paragraph to explain

## Commerce Direction

The carousel should create desire and recognition. The caption or profile link can route to affiliate products.

Do not make the carousel itself look like a shopping catalog until the account has proven reach and click behavior.
