# 聯盟商品選品規則

## 第一階段優先品類

優先：
- 包包：尺寸容錯高，退貨風險低。
- 鞋：視覺辨識強，但需標註尺寸風險。
- 外套：客單較高，穿搭圖辨識度高。
- 飾品：容易作為加購與風格補強。
- 寬鬆上衣：尺寸壓力較低。

暫緩：
- 貼身褲、內衣、泳裝。
- 尺寸非常敏感的單品。
- 高仿精品、明顯侵權商品。
- 過季庫存不穩定商品。

## 商品清單欄位

| 欄位 | 說明 |
| --- | --- |
| product_name | 商品名稱 |
| category | 品類 |
| price_tier | 平價、質感、替代款 |
| source | 蝦皮、品牌官網、Amazon、ShopMy |
| affiliate_url | 聯盟連結 |
| visual_match_score | 與 AI 圖搭配相似度 1-5 |
| conversion_risk | 尺寸、庫存、價格、評價風險 |
| content_bucket | 對應內容桶 |

## 商品推薦原則

- 每套穿搭至少準備 3 個商品層級：平價、質感、替代款。
- 不把 AI 圖描述成實際商品試穿照。
- 商品圖與 AI 圖差異過大時，要說明是相似款或靈感款。
- 商品連結失效或售完時，每週替換。
