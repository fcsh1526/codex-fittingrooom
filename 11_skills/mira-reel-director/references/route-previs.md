# 共享場景、雙路徑與相機視角預演

適用於連續行進、繞拍或要求同場地連貫的影片。左右並排與獨立日常片段不必強加此模型。

## 同一份資料產生兩種視圖

1. **空間：** 固定座標軸、單位、地面和地標。單位若只是示意，不能稱公尺或測量場地。柱、牆、路緣、斑馬線和門口是固定幾何；衣服切換不能重設它們。
2. **人物路徑 P(t)：** 位置、面向、動作／步相和服裝，使用整片共同時間。先選走路風格，再安排路程與時間；不能讓人物每到換裝點就停下。
3. **相機路徑 C(t)：** 獨立的地面曲線、高度、拍攝朝向或目標點，以及視角／焦距的表示法。不能只以固定距離和角度偏移人物路徑冒充已設計好的獨立軌道。
4. **投影：** 相機視圖、人物在畫面的位置／大小、景物可見性均由同一 P(t)、C(t)、場地及鏡頭模型算出。俯視圖與正面動畫不能各自手畫再宣稱一致。

獨立不代表兩條路徑互不相干。兩者必須配合服裝閱讀、人物在框位置、相對角度和景物視差；可共同優化控制點，但保留分開的路徑資料。

## 時間與曲線

曲線控制點的間距不等於恆定行走速度。曲線位置插值、時間插值與沿線移動速度要分開規劃；需要均速時依弧長安排時間，起步、轉彎、停下則明確設計。避免每個鏡頭重新套一次ease-in/ease-out，造成忽快忽慢。

同一連續路線的鏡頭交疊期間，兩來源描述的是同一段世界時間，而不是同一條路線的兩個不同位置。先在預演中得到整段重疊的構圖／步相，再導出前後素材；只讓一張接點圖相同不足以證明0.75秒都能接。

## 每個關鍵時刻要看什麼

記下時間、人物位置／面向、相機位置／朝向、相對距離／角度、人物框內高度／中心、可見衣服／地標及步相。首、中、尾與接點之外，檢查轉彎最強、遮擋最深、距離最近與尺度變化最大的時刻。

| 檢查 | 失效示例 | 修正位置 |
| --- | --- | --- |
| 空間合理 | 相機穿柱，人物斜穿花台，門口換位置 | 共同場地／路徑 |
| 動勢連續 | 換套忽然停步，相機突然繞到反側 | 路徑時間、速度與朝向 |
| 穿搭可讀 | 後側占太久，全身變成僅見上半身，包一直出框 | 構圖、取景時間與鏡頭目的 |
| 視線舒服 | 人物忽大忽小，背景線跳位，接點雙臉雙腳 | 接點重疊中的尺度、相位與位移 |
| 生成可執行 | 太多精確地標、角色交互與複雜運鏡同時改變 | 縮短有界單鏡或簡化設計 |

檢查相對速度與加速度的突變，而非只看每個參數在某個瞬間都合法。相機角度變化快、人物尺度變化快、同時換衣且背景高對比，可能各項單獨能接受、組合後卻閃眼；應把這些變化錯開或減少。

## 預演的可靠程度

如果沒有可用的共用空間投影器，先做可靠的靜態關鍵視圖和相符俯視圖，標示動態尚未驗證。不要用不相符的動畫再靠文字說明補足。線稿肢體可以簡化，但相機角度、畫面尺度、方向與地標不能只是裝飾。

幾何預演確認的是設計。生成影片仍須檢查它是否大致遵循、腳是否滑、背景是否重建錯誤。首尾或片內參照只能提供條件；不能由圖被接受或工具回覆成功，推論引擎已精確執行軌道。
