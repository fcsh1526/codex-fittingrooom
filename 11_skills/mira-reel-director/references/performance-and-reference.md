# 情境中的人物表演與參考拆解

更新：2026-11-03。用於Mira自然表演、參考研究與提示詞比較；不另開週產契約。

## 2026-11-06：六種方法內的表演優化

方法庫列六種既有剪輯方法及兩種待研究方法。動作豐富的左右比較仍屬左右並排；同一方法內可以有不同且更好的表演，不因動作／表情進步重新計數。當前改善重點是人物動作、表情、情緒細節，不以換方法或增加轉場本身作為改善證據，也不要求每次生成前對照已接受片段。

把表演寫入既有分鏡與提示詞，依看點挑必要細節：人物正在做什麼、注意誰或什麼、身體如何接續反應、表情如何隨情境發展。可用有態度的造型展示或生活互動，不必每片編劇情。動作幅度、節奏及停頓依情境安排；保留自然變體，不把細膩寫成微幅搖擺，也不把更多動作理解為跳舞或持續堆手勢。

選段時保留動作起因、主要反應及合理收尾；細節鏡頭／裁切的時機須顧及臉與身體正在傳達的訊息。審查表演是否連貫、情緒可理解、眼神與身體連動，並維持身份、肢體和服裝品質檢查。單次成功仍不證明可穩定複製。

## 從看點到表演

像指導演員一樣，先讓人物知道自己正在做什麼、注意誰或什麼、為何及如何反應，再把這些轉成生成模型能理解的可見動作。分鏡記人物目的、注意對象、可見反應及動作銜接，提示詞保留簡短原因與必要節點。例如「等候的朋友已在鏡頭旁，她在路緣確認來車，回看行進方向再跨出，走近時對朋友笑開」。實際方向與路緣位置依首圖設定，結果仍由原速影片確認。

先定觀眾看什麼，再連結「情境／人物目的 → 注意對象 → 關鍵可見反應 → 身體動作與情緒發展」。例如過街前察看車流、聽到朋友招呼而回看、接到飲料而回應店員。生活原因須與場景位置及手中物件一致，不能為增加動作而堆轉頭、舉手、扭肩與走路。

行走、站姿、側步、入出畫都可選，幅度依觀看目的安排。細膩不等於動作一律小，也不要求每秒都有新手勢。視線、表情、重心、手臂、提物與衣料需要合理連動，開頭、發展與收尾有可辨變化，同時保留服裝資訊。

提示詞可優先試「簡短可見情境／動機＋必要動作順序」。只寫故事會讓引擎自行選動作，只列機械動作又可能失去注意對象與因果；依實片取捨，不預設越長越準。只鎖與看點、空間及接點有關的關鍵節點，其餘保留自然變化，不把眨眼、轉頭角度或每秒編舞當普遍硬規格。

## 參考分析的證據

分開記錄三類資訊：

- 工具實際輸出：規格、分段、抽格時間與完成／失敗步驟。
- 可見行為：眼神／頭的方向、腳相對路緣／地面的狀態、物件接觸等。
- 動機解讀：是助理推論、文案支持，還是使用者已澄清；不確定就標示。不能將側看直接等同調情或看鏡頭。

動機不明時，回看事件前後的場景與行為，再決定是否要密集抽格或釐清。不要僅憑孤立表情指定劇情。語意欄空白就是未產出語意；成功抽格不等於自動理解故事。觀看範圍、音訊分析、原速全片審查分開如實記錄。

參考可作研究，也可在已授權時仿拍；後續正常Reel不必一直複製他人。與原片時間／動作順序不同，若依自身場景仍有合理因果，可保留為表演變體。合理性、吸引力與肢體品質分開評價，不以逐秒相同作唯一合格條件。

## 小型比較與累積

只有比較能回答當前製作問題時才做。固定已核准首圖、身份、服裝、鏡頭、片長與可用設定；比較原因句時，兩組保留同一套完整可見動作，只增刪原因句。不要比較簡陋走路與豐富表演卻稱只有一個變因。

保存凍結提示詞、來源／輸出ID、實際設定、生成次數與可用段。能固定seed便記錄；不能固定、模型版本不可選或內部呼叫不可見時明示。代理回報原文傳入與直接驗證不同；單次偏好不能確定措辭因果或成功率。

先保留完整原速對照，再另存剪輯候選。不能為使某組更好而只剪該組、改速或藏失敗。單片接受、相對偏好、跨人物／情境再次成立、發布成效分開記錄。研究服務製作；有可用方向後，在既有授權的新內容中逐步觀察轉用結果，不以大量A/B取代正常Reel。沿用有界重試與付費／重大方向變更說明要求。

## 審查與工具角色

- 表演：注意對象與反應合理，動作銜接連貫，笑容有發展，沒有與後段不接的多餘手勢。
- 品質：身份／頭身、手腕手指、腳掌接地、衣服提物、路緣／背景幾何；表演吸引力不能抵銷實質變形。
- 構圖：用實際照片及影片檢查人物大小、完整讀衣區間與近景目的；保留生成與預演偏差，不倒改原計畫聲稱完全遵循。
