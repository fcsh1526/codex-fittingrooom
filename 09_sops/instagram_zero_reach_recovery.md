# Instagram Zero-Reach Recovery SOP

Created: 2026-06-12

Use this SOP when a new Instagram post remains at or near zero reach for more than 24 hours.

## Current Case

Post:

```text
https://www.instagram.com/p/DZCTbtWGuhx/?igsh=aG9kcjl3OWIybm01
```

Published:

```text
2026/06/01 16:08
```

Reported status on 2026-06-12:

```text
10+ days with no exposure / reach.
```

## Interpretation

If a post has `reach = 0` for several days, do not treat it as a content-quality failure.

The likely issue is one of:

- account is private or restricted
- post is not visible on profile grid
- account has no initial audience
- new account has no distribution signals
- post has no external trigger
- caption/hashtag/profile setup is incomplete
- Instagram did not index or distribute the post

## Do Not Do Yet

Do not spend time on:

- affiliate product list
- paid product research
- media kit
- brand outreach
- performance conclusions

Those require non-zero distribution first.

## Step 1 - Visibility Audit

Check these manually in Instagram:

1. Account is public.
2. Post is visible on the profile grid.
3. Post is not archived.
4. Post is not set to close friends or limited audience.
5. Account status has no recommendation restriction.
6. Profile photo, bio, and username look complete.
7. Post caption has disclosure and at least a few relevant hashtags.
8. The post can be opened from another account or browser.

## Step 2 - Add A First Comment

Add this comment under the post:

```text
想看同風格清單可以留言「沙色套裝」，我會整理平價 / 質感 / 替代款。
AI 虛擬穿搭示意，非真人試穿。
```

## Step 3 - Manual Seed Traffic

Do a small, clean traffic test:

1. Share the post to Instagram Story once.
2. Send the post to 3-5 trusted people.
3. Ask them to open it naturally.
4. If they like the content, ask them to save or comment.

Do not:

- buy traffic
- use engagement pods
- spam comments
- repost aggressively

## Step 4 - Publish A Simpler Second Test

If the first post remains at zero after the visibility audit, publish a simpler second test:

- 1 image, not panorama
- clear full-body outfit
- short caption
- direct question CTA
- 8-12 hashtags
- same AI disclosure

Suggested second-test angle:

```text
「上班不想太正式，沙色西裝套裝可以嗎？」
```

Suggested CTA:

```text
你會穿這種沙色套裝上班嗎？留言 1=會，2=不會。
```

## Pass / Fail Criteria

Pass:

```text
reach >= 20
```

Strong pass:

```text
reach >= 100
saves >= 1
comments >= 1
```

Fail:

```text
reach = 0 after account audit and manual seed traffic
```

If fail, the next action is account/channel setup, not content iteration.

## Channel Backup Plan

If Instagram continues to show zero reach:

1. Keep Instagram as archive/portfolio.
2. Test Pinterest with the same visual assets.
3. Test Threads text post with one image.
4. Test Xiaohongshu if account setup is ready.
