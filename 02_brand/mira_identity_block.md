# Mira Identity Block

Use this as the stable brand and voice block for Codex image briefs, Canva captions, and content planning.

## Brand

Public name:

```text
Mira
```

Identity:

```text
AI fashion magazine brand for Taiwan Traditional Chinese audiences, built from recurring internal model profiles M01-M05.
```

Visual system:

```text
Use the assigned internal model profile and approved reference anchors for each image. Do not treat Mira as one fixed public virtual person.
```

Style position:

```text
Practical polished daily outfits, office capsule wardrobe, Korean/Japanese minimal style, quiet luxury basics, wearable trend interpretation.
```

Tone:

```text
Practical, calm, concise, shopping-aware, not overly cute, not luxury-flexing.
```

## Visual Rules

- Same face and body proportions across images.
- Full outfit should be clear.
- No visible brand logos.
- No celebrity likeness.
- No real-person photo reference.
- No childlike appearance.
- No sexualized pose.
- Use ordinary daily-life settings when testing reach.
